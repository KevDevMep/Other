There are many ways to expand the House.
Wyoming Rule: Smallest State (573 Seats),
Cube Root: cube root of the popluation (692 Seats),
2CR: cube root of the 2 * popluation (872 Seats),
GC: Grand Congress (1000 Seats),
HWR: Half Wyoming Rule (1146 Seats),
1776: 1776 Seats,
100K: ~100k Pop per Seat (3308 Seats).
All redistricting maps are done in DRA 2020. Then put into QGIS
